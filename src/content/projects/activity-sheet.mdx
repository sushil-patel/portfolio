## 1. Project Overview

**ActivitySheet** is a Spring Boot backend microservice designed for enterprise time tracking and labor auditing. It allows employees to log their daily working hours, task descriptions, and project associations while providing administrative endpoints to query and audit departmental time expenditures.

---

## 2. Key Technical Implementations

- **Layered Architecture:** Built following the classic Spring enterprise architecture—decoupling REST controllers (`EmployeeDataController`), service interfaces (`ActivitySheetService`), and persistent data access (`EmployeeDaoJpaImpl`).
- **Custom JPA DAO Implementation:** Implemented explicit `EntityManager` interactions to handle custom transactional boundaries and query aggregations across employee activity entities.
- **Centralized Exception Handling:** Engineered `ActivitySheetExceptionHandler` to intercept `EmployeeNotFoundException` and runtime constraints, returning standardized `EmployeeErrorResponse` payloads with HTTP 404/400 statuses.
- **Cross-Origin Configuration:** Structured `WebConfig` with explicit CORS mappings to securely integrate with disparate internal client applications and dashboards without wildcard vulnerabilities.
