## 1. Project Overview

**CLI Alarm** is a focused command-line utility built to automate focus intervals, deployment timer alarms, and developer alert notifications directly from the terminal without bloated GUI background processes.

---

## 2. Key Features & Implementation

- **Low-Overhead Execution:** Runs with minimal RAM overhead (< 15MB), making it ideal for background terminal multiplexers (tmux/screen) during lengthy server operations.
- **Graceful Signal Handling:** Captures `SIGINT` and `SIGTERM` signals to allow clean terminal exits without leaving orphaned timer threads.
- **Asynchronous Dispatch:** Non-blocking timer loops that decouple system sleep intervals from prompt listeners.

## 3. Technology Stack

- **Language:** Python
- **Ecosystem:** POSIX / Windows audio hooks, Command-line argument parsing
